# Турнир "Решись"

Проект создан в спешке для участия в турнире **Решись**.

## Запуск проекта
```bash
pip install -r requirements.txt
```

```bash
python run.py
```

## Зависимости
- fastapi
- uvicorn[standard]
- sqlalchemy
- python-jose[cryptography]
- passlib[bcrypt]==1.7.4
- bcrypt==4.3.0
- pandas

## Важное предупреждение

**Проект не предназначен для использования в проде.**

Он был разработан в ограниченные сроки и в спешке, и вообще не рекомендован к импользованию, не проходил полноценного тестирования кода и проверки безопасности.

В проекте могут присутствовать серьёзные ошибки, в том числе уязвимости, которые могут привести к утечке данных или несанкционированному доступу.

Впринципе проект, кроме как для турнира, бесполезен.
